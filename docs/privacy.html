Herdie privacy policy

Last updated: 7 September 2026

Herdie is an SSH client for iPhone and iPad, developed by Lucas Scariot. It connects your device to a host you choose. You do not need a Herdie account.

Information on your device

Herdie stores saved connection details, preferences, recent terminal previews, and any retained drafts on your device. Saved SSH passwords and private keys are stored in iOS Keychain. Terminal output can contain sensitive information from your host; keep that in mind when sharing screenshots or copying output.

You can manage saved connections in the app. Deleting a connection removes the credentials associated with that connection from Keychain.

SSH connections

Herdie sends authentication information, terminal input, and connection traffic directly to the SSH host you select. It receives terminal output from that host. There is no Herdie terminal relay. The operator of your SSH host controls that host's logs and data retention.

Public configuration request

Herdie requests a small JSON file from a public configuration endpoint to determine whether to show an optional support link in About. The request does not include SSH credentials, hostnames, terminal input, or terminal output. GitHub Pages hosts this configuration file and these support pages. GitHub logs and stores visitors’ IP addresses for security purposes, including visitors who are not signed in. This is network information, not SSH credentials or terminal content. See GitHub’s privacy statement for its handling of this information.

Analytics and external links

Herdie includes no analytics SDK or advertising tracking. It does not send terminal content or SSH credentials to its developer.

If you open a link to the developer's website, social profiles, support services, or a URL found in terminal output, that destination receives the request and its own privacy practices apply. Supporting the developer is optional and does not unlock app features.

Support

When contacting support, include only the information needed to describe the problem. Do not include passwords, private keys, access tokens, or sensitive terminal output.

Contact: lucas@scariot.fr

Changes

This policy will be updated if Herdie's data handling changes. The date above identifies the latest revision.
